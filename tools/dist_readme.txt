Vanguard Sovereign OS — одиночный исполняемый файл
==================================================

Запуск
------
Распакуйте архив в любую папку (не в «Program Files» — приложение пишет
рядом с собой свои файлы) и запустите vanguard_os.exe.
Экран «PRESS ANY KEY» — не зависание: нажмите любую клавишу, и появится
рабочий стол. Дальше всё управление — строка команд внизу окна, `/help`
покажет список команд.

В архиве один файл: при запуске с флагом `--core` тот же exe работает
ядром, поэтому отдельный vanguard_core.exe рядом не нужен.

Что для чего нужно
------------------
- Рабочий стол, терминал, проводники, записки, телеметрия — работают сразу,
  ничего устанавливать не нужно.
- Нейро-ответы (ИИ) — нужен локальный Ollama: https://ollama.com
    ollama pull qwen3.5:9b     (скачать модель, ~7 ГБ)
    ollama serve               (запустить сервис)
  Без Ollama всё остальное работает, но запросы к ИИ отвечают ошибкой сети.
- Команда /run — нужен Python 3 в PATH: https://www.python.org
- Компиляция Rust-кода, который просит ИИ, — нужен rustc в PATH:
  https://rustup.rs

Файлы приложения (создаются рядом с exe)
----------------------------------------
  vanguard_notes.txt        записки
  vanguard_settings.json    настройки
  vanguard_dialogues.jsonl  журнал диалогов (датасет для дообучения)
  vanguard_gen_<id>.py      скрипты, созданные ИИ (список — команда /apps)

Сеть
----
Ядро слушает 127.0.0.1:7331 — только локально, наружу не выходит.
Ollama используется на localhost:11434.
